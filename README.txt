كافيه طلة الشمالي - PWA Install Edition (Verified)

هذه النسخة مجهزة للتثبيت كتطبيق PWA باستخدام نافذة التثبيت الأصلية في Chrome عندما يقرر المتصفح أن الموقع قابل للتثبيت.

تم التحقق من:
- manifest.json صالح ويحتوي name/short_name/icons 192 و512/start_url/scope/display.
- جميع ملفات الأيقونات المطلوبة موجودة وبالأحجام الصحيحة.
- Service Worker صالح نحويًا وجميع ملفات الـcache موجودة.
- JavaScript المضمن في index.html صالح نحويًا.
- مراجع عناصر DOM المستخدمة في JavaScript موجودة.
- زر "📱 تثبيت التطبيق" يستخدم beforeinstallprompt وprompt() الأصلي.
- حدث appinstalled يخفي زر التثبيت بعد التثبيت.
- الموقع يعمل عبر HTTPS عند نشره على Netlify أو استضافة HTTPS.
- تم ترتيب ملفات الموقع في جذر ZIP حتى لا يتم نشرها داخل مجلد app بالخطأ.

مهم:
- افتح الموقع من Chrome على Android.
- ظهور beforeinstallprompt يعتمد على المتصفح وحالة التثبيت ومعايير PWA؛ لا يمكن للموقع إجبار نافذة النظام على الظهور تلقائيًا في كل جهاز.
- عند ظهور زر التثبيت داخل الموقع، الضغط عليه يفتح نافذة Chrome الأصلية (Install app).
